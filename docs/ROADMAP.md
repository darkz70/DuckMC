## Вариант A — Tauri 2 (рекомендую) ⭐

Один проект на Rust + наш готовый веб-интерфейс. Поддерживает **все 5 платформ**,
включая Android и iOS. Маленький вес (~10 МБ), системный webview, полноценный
доступ к ОС (запуск java-процесса, файлы, PackageManager на Android).

- ✅ одна кодовая база на все платформы, крошечный размер
- ✅ настоящий нативный запуск игры (`std::process::Command` / `jni`)
- ✅ без ограничений CORS для авторизации
- ⚠️ нужен Rust-тулчейн; на iOS запуск Java Edition невозможен (ограничение платформы) — там будет Bedrock/удалённый запуск
- 📦 этапы: `npm run build` → Tauri-проект `src-tauri` → команды `launch_java`, `launch_bedrock`, `pick_dir`, `save_tokens`

## Вариант B — Capacitor (Android-first, быстрее всего выйдет на телефон)

Наш веб-UI заворачивается в нативное Android-приложение (iOS позже тем же кодом),
десктоп — через Electron тем же UI.

- ✅ самый быстрый путь до «работает на моём Android»
- ✅ плагины: файлы, тосты, установка APK-пакетов Bedrock
- ⚠️ десктоп всё равно потребует второй обёртки (Electron)

## Вариант C — Electron + React Native

Классика десктопных лаунчеров + отдельное мобильное приложение.

- ✅ максимально «родные» десктопные возможности
- ❌ два приложения вместо одного, дублирование логики — самый запутанный путь

## Порядок работ (независимо от варианта)

1. **Шаг 1 — готово:** интерфейс, настройки, аккаунты, список версий. ✅
2. **Шаг 2:** подключить нативный движок (выбрать A/B/C) — реальные загрузки файлов клиента
   (клиент, библиотеки, ассеты из `piston-meta`), распаковка `natives`, `java-process`.
3. **Шаг 3:** Java-рантайм: авто-подбор Java 8/17/21 под версию, скачивание Temurin/JRE.
4. **Шаг 4:** полная цепочка авторизации Microsoft (XBL → XSTS → Minecraft) и ely.by join-server.
5. **Шаг 5:** Android: запуск Bedrock (обнаружение установленной игры), потом iOS.
6. **Шаг 6:** моды/скины/серверы, Discord RPC, автообновления лаунчера.

## Юридические рамки (важно)

- Java Edition: файлы распространяются Mojang, лаунчер качает **только с официальных
  серверов** и требует валидной сессии аккаунта.
- Bedrock: платное приложение — только обнаружение установленной копии или ссылка в
  официальный магазин (`docs/bedrock.md`).
